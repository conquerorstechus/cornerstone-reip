The problem

Good deals die in the inbox.

Independent investors and small shops still underwrite from Zillow tabs, broker blasts, and a spreadsheet that only one person understands.

Hours per name, not minutes

  • A junior analyst spends half a day pulling rent, tax, HOA, insurance, and a mortgage quote.
  • No shared stack — every partner models 20% down, 5% vacancy, and a different insurance line.
  • The weekly “best of” email is handmade. It does not survive vacation.

Four asset types, four toolchains

  • Townhomes live in Zillow. Land lives in the county GIS. Multifamily lives in an OM PDF.
  • Area thesis is tribal knowledge (“Wesley Chapel HOAs kill cash flow”) with no score.
  • Automation exists (n8n, Apify) but it is not wired to an investor-grade report.

Architecture

n8n does the fetching. RIP does the thinking.

1 · Trigger

Operator hits Analyze, or Friday 8am fires the digest. RIP creates a run ID and POSTs to the matching webhook with x-webhook-secret.

2 · Enrich

n8n pulls Zillow / Apify, county GIS, FEMA, rent comps — or runs the bundled Code node. Same payload shape either way.

3 · Report

Callback to /api/webhooks/n8n. RIP stores the run and renders the IC page. If n8n is down, the local engine still underwrites.
